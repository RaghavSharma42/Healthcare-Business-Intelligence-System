# Healthcare Business Intelligence System

An end-to-end healthcare data analytics project built using SQL, Microsoft Excel, and Power BI.

The project analyzes healthcare operations including patients, doctors, appointments, treatments, billing, insurance providers, and payment methods to generate business insights and interactive dashboards.

## Project Objective

The objective of this project is to demonstrate an end-to-end business intelligence workflow:

- Store and query healthcare data using SQL
- Perform business analysis using Excel
- Build interactive dashboards using Power BI
- Create business KPIs and analytical measures using DAX

## Dataset

The project consists of five related datasets:

- Patients
- Doctors
- Appointments
- Treatments
- Billing

These datasets are connected using patient, doctor, appointment, and treatment identifiers.

## SQL Analysis

SQL was used to create the healthcare database and perform business analysis.

Key concepts used:

- SELECT and filtering
- GROUP BY
- Aggregate functions
- HAVING
- CASE statements
- Subqueries
- Window functions
- ROW_NUMBER
- Business-focused analytical queries

The SQL analysis includes appointment trends, treatment costs, insurance provider analysis, and healthcare operational insights.

## Excel Dashboard

Microsoft Excel was used to perform exploratory business analysis and create an analytical dashboard.

Key features:

- Excel Tables
- KPI calculations
- PivotTables
- PivotCharts
- Appointment status analysis
- Doctor workload analysis
- Revenue by treatment
- Payment method analysis
- Insurance provider analysis

## Power BI Dashboard

An interactive Power BI dashboard was developed using a relational data model and DAX measures.

### Key KPIs

- Total Patients
- Total Doctors
- Total Appointments
- Total Treatments
- Total Revenue
- Average Revenue per Appointment
- Appointment Completion Rate

### Power BI Features

- Data modeling and table relationships
- DAX measures
- CALCULATE
- DIVIDE
- REMOVEFILTERS
- Filter context
- Interactive cross-filtering
- Appointment status slicer
- Drill-through analysis

## Doctor Performance Drill-through

A dedicated Doctor Performance Details page allows users to drill through from the main dashboard and analyze individual doctors.

The page includes:

- Doctor ID
- Total appointments
- Revenue generated
- Appointment status breakdown
- Treatments handled
